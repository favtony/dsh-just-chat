# dsh-just-chat

`dsh-just-chat` 是 DSH Web 的外部插件，为不属于已添加工作区的对话提供独立入口。

## 兼容性

- DSH `0.1.1-rc.2`
- Node.js `^22.19.0 || >=24.0.0`

## 安装

从插件目录安装开发版本：

```powershell
dsh plugin --profile <profile> add link:<插件绝对路径>
```

从打包产物安装：

```powershell
dsh plugin --profile <profile> add <dsh-just-chat-版本号.tgz 的绝对路径>
```

插件接管默认工作区选择、输入栏和侧栏工作区区域；不要与其他接管相同区域的插件同时启用。

## 使用

1. 在新建对话的工作区选择器中选择“`不在项目中工作`”。
2. 输入纯文本后发送。此时才创建目录和真实会话。
3. 在设置中的“`对话目录`”填写根目录和目录名模板。

未发送的文本会在刷新或重新打开后恢复。自动创建的会话显示在侧栏“`对话`”区域，工作区与对话搜索互不影响。
